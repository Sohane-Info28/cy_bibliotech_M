# Cy_BiblioTech

Projet de gestion de bibliothèque développé en langage C dans le cadre d’un projet scolaire.

## Présentation

Cy_BiblioTech est une application console permettant de gérer une bibliothèque. Le programme propose différentes fonctionnalités comme la gestion des livres, des utilisateurs, des emprunts ainsi que la recherche et le tri des données.

Ce projet a été réalisé afin de mettre en pratique :

* la programmation en langage C ;
* la manipulation de fichiers ;
* l’organisation d’un projet structuré ;
* l’utilisation de Git et GitHub.

## Fonctionnalités

* Gestion des livres
* Gestion des utilisateurs
* Gestion des emprunts
* Recherche de livres
* Tri des données
* Menus interactifs
* Sauvegarde des informations dans des fichiers
